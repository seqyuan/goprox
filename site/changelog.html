更新日志

v0.4.0 — 2026-08-15

  • 原生 TLS 终结：--tls-selfsigned 自动生成覆盖 localhost + 局域网 IP 的自签证书并直接提供 HTTPS；整个站点成为安全上下文，代理应用的 crypto.randomUUID / crypto.subtle / navigator.storage 等安全上下文 API 全部原生可用。也可用 --tls-cert/--tls-key 指定自有证书。
  • 默认服务（default_service）：未被认领的裸路径确定性地路由到指定服务——根路由型 SPA（Nuxt/Next 客户端路由）在网关根路径零改动运行；资源类路径（静态文件、/api/、/_nuxt/）仍跟随页面 Referer。
  • 兼容性全面增强：同源 Origin 改写（通过后端 Host/Origin 栅栏）、WebSocket 101 与 bwlimit 兼容、安全上下文 API polyfill、裸路径 Referer 优先、日志静默、-V/--version。
  • 本地优先应用零改动接入：「dsh 配置示例」页面，演示 DeepSeek Harness 这类只监听回环、自带信任栅栏的应用如何直接通过网关使用。

v0.3.0 — 2026-08-15

  • 两步验证（TOTP）可选二次验证：按用户开启（默认关闭），扫码绑定自助完成，动态码校验 ±1 个 30s 窗口容错并独立限速；goprox 2fa-reset 供管理员重置。
  • 公网部署 TLS 文档：Caddy / nginx 反代终结 TLS 完整示例，--host 127.0.0.1 + --trusted-proxy 配套做法。
  • 自定义站点标题：--title "🧬 生信分析平台" 替换登录页/仪表盘/404 标题，写入 state.yaml 持久化。
  • Apple Liquid Glass 视觉重设计：冷灰底色 + 系统字体、毛玻璃导航、白色卡片双层阴影、单渐变 monogram、pill 化控件、玻璃弹窗与弹簧动效。
  • 示例补充：局域网 IP（192.168.0.109）与单 HTML 网页（backend_path 指向入口文件）。
  • 新增依赖 github.com/skip2/go-qrcode（TOTP 二维码生成）。

v0.2.6 — 2026-08-15

  • CLI 精简：删除 start / stop / status 与整个守护化机制（pidfile、Setsid、就绪轮询），goprox serve（或裸 goprox）成为唯一启动命令，前台运行、Ctrl+C 停止。
  • 后台运行改为 tmux/screen 或 nohup；执行旧命令会打印「已移除」提示与替代方式。
  • 配置目录不再生成 daemon.pid / goprox.log。

v0.2.5 — 2026-08-15

  • 自引用检测（防死循环）：后端指向网关自身时（host 解析到本机接口 IP 且端口等于网关监听端口），写入配置与拨号建连两处都会拒绝。
  • 按服务带宽限速：服务新增 bwlimit 字段（字节/秒），上行/下行分别限速；仪表盘新增「带宽上限」输入框与卡片限速徽章。
  • 新增 golang.org/x/time 依赖（限速令牌桶）。

v0.2.3 — 2026-08-15

  • 拒绝链路本地 / 云元数据地址（防 IMDS 凭据窃取）；修复 DNS rebinding 绕过（SafeDialContext 拨号时重校验）。
  • 不再透传客户端伪造的 X-Forwarded-For；会话绑定密码哈希版本（改密即吊销）；登录时序防用户枚举。
  • 网关页面防点击劫持 / MIME 嗅探；请求体超限返回 413；慢速请求体防护（ReadTimeout）。
  • <base> 改为目录级注入；清理代理重写后的 RawPath。

v0.2.2 — 2026-08-15

  • 卡片 favicon 支持现代图标（.ico/.svg/.png 候选链）；多服务下绝对路径资源 404 修复（route cookie 回退）。
  • 静态资源保留压缩（端到端 gzip），HTML 仍由 Transport 解压以正确注入 <base>。
  • 管理 API 与登录 CSRF 防护；服务 path 安全校验；重定向改写重构；服务名校验。
  • 大 HTML/分块响应内存保护；模板安全加固（防 </script> 注入）。

v0.2.1 — 2026-08-11

  • 修复 gzip 压缩的 HTML 被 <base> 注入破坏；修复 route cookie 认证绕过；修复登出后 /login 被劫持。
  • 登录限流加固（--trusted-proxy、全局清扫 + 10k 硬上限）；密码哈希升级为 bcrypt（兼容旧哈希）。
  • HTTP Server 增加 ReadHeaderTimeout/IdleTimeout；HEAD 请求不再做 HTML 注入。

v0.2.0 — 2026-08-11

  • 配置集中到程序目录 config/（state.yaml、users/），整个目录可整体拷贝迁移。
  • 新增 goprox user / goprox del；passwd 改为管理员重置；start 后台启动修复。
  • bare 路径正确重定向到 /proxy/<用户>/<服务>/；中文服务名唯一化；优雅停机 + 共享 HTTP transport。
