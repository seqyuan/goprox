安装与启动

拷贝、建号、启动 —— 三条命令上线。

安装

go install github.com/seqyuan/goprox@latest

安装后 goprox 位于 $GOPATH/bin（通常是 ~/go/bin）。

请把二进制拷贝（不是链接）到独立目录再运行。 所有配置都存放在二进制旁边的 config/ 目录，整个目录可以整体拷贝、备份、迁移。 os.Executable 会解析符号链接，所以不要用 ln -s 链接， 否则配置会落在链接目标的真实路径下。
mkdir -p /opt/goprox
cp ~/go/bin/goprox /opt/goprox/

启动

GoProx 只有前台运行这一种模式，Ctrl+C 优雅停机：

./goprox serve --port 1908

需要常驻后台时：

# tmux / screen 会话
tmux new -s goprox -d './goprox serve --port 1908'

# 或 nohup
nohup ./goprox serve --port 1908 > goprox.log 2>&1 &

命令参考

./goprox serve [options]    启动网关（前台运行，Ctrl+C 停止）

# 用户管理（管理员）
./goprox user <name>        创建用户账号（交互设置密码）
./goprox passwd <name>      重置用户密码
./goprox del <name>         删除用户账号
./goprox 2fa-reset <name>   关闭指定用户的两步验证

# 轻量级单点登录（可选）
./goprox sso                                查看当前 SSO 配置
./goprox sso --user-header X-Authenticated-User \
            --hmac-secret <key>              启用（身份头 + HMAC 签名）
./goprox sso --off                           关闭 SSO

Options

选项说明
-d, --config-dir <dir>配置目录（默认 <程序目录>/config）
--host <host>监听地址（默认 0.0.0.0）
--port <port>监听端口（默认 1908）
--trusted-proxy <cidr>可信反向代理网段（如 127.0.0.1/32），启用后信任其 X-Forwarded-For/Proto 头（默认不信任）
--tls-cert <file>TLS 证书（PEM），与 --tls-key 一起启用 HTTPS
--tls-key <file>TLS 私钥（PEM）
--tls-selfsigned生成自签证书（覆盖 localhost + 局域网 IP）并启用 HTTPS——整个站点成为安全上下文，代理应用的 crypto.randomUUID / crypto.subtle / navigator.storage 等安全上下文 API 全部可用
--title <text>页面左上角站点标题（默认 GoProx），支持中文/emoji
-h, --help显示帮助

SSO 选项（goprox sso）

选项说明
--user-header <name>携带登录用户名的请求头名（如 X-Authenticated-User）；每个被代理的请求都会带上 user_header: <用户名>，后端读取即知当前用户。详情见安全页面
--hmac-secret <key>可选共享密钥：同时下发 user_header-Signature（HMAC-SHA256，base64url），后端验签后不再依赖网络隔离
--off关闭 SSO（清除 user_header 与 hmac_secret）
后端必须只能经网关访问（只监听回环或防火墙仅放行网关）。 身份头是后端的唯一身份凭证，任何能直连后端的人都能伪造 X-Authenticated-User: admin； 无法保证网络隔离时务必设置 --hmac-secret。改动后重启网关生效。

user / passwd / del / 2fa-reset 需要与网关相同的目录写权限（root 启动的网关，管理命令也用 root 执行）。 用户名需写在选项之前：goprox user alice -d /opt/goprox/config。

目录结构

/opt/goprox/
├── goprox                  # 二进制
└── config/                 # 0700，网关属主
    ├── state.yaml          # 网关状态（监听地址/端口、trusted_proxy、title、session_secret、sso）
    └── users/              # 每个用户一个独立配置文件
        ├── alice.yaml
        └── bob.yaml

多用户共享同一端口：登录后每个用户只能看到和管理自己的服务，访问路径为 /proxy/<用户名>/<服务>/。
