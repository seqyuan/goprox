一台服务器
一个 Web 入口，各管各的

GoProx 是面向实验室、登录节点的多用户认证反向代理网关。 运维启动一个共享网关并创建账号，每个用户登录网页管理自己的 Jupyter / RStudio / 内网服务， 无需每人记不同端口。

快速开始 GitHub ↗

多用户隔离

所有用户共享一个网关端口，登录后只能看到和管理自己的服务。

完整认证

bcrypt 密码 + 签名会话 + 登录限速，可选 TOTP 两步验证。

轻量级 SSO

把登录用户名带给后端（可选 HMAC 签名），挂在网关后的服务免登录识别用户。

路径重写

支持后端挂在子路径或单 HTML 文件入口（backend_path）。

WebSocket

Jupyter、RStudio 等实时服务开箱即用。

带宽限速

按服务设置 bwlimit，防止单个用户拖垮共享带宽。

公网就绪

配合 Caddy/nginx 反代终结 TLS，支持两步验证。

快速开始

三步即可上线：

# ① 把 goprox 拷贝到独立目录（见「安装」）
cd /opt/goprox

# ② 管理员创建用户账号（交互式设置密码）
./goprox user alice
./goprox user bob

# ③ 启动网关 —— 日常只需记住这一条命令
./goprox serve --port 1908

浏览器访问 http://lab.example.com:1908/ 登录；登录后点 + 添加服务卡片、拖动排序、点击卡片访问。

两步验证（TOTP）默认不开启，纯密码即可登录； 需要时在仪表盘点「两步验证未开启 · 开启」自助绑定，详见安全。
