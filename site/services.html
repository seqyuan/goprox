服务卡片与示例

用户登录后在仪表盘管理自己的服务卡片：+ 添加、✎ 编辑、 × 删除、⋮⋮ 拖动排序。

用户配置示例

config/users/<用户名>.yaml：

auth:
  password_hash: "$2a$10$YVpm1R6puQFltjmrKziLsujVtAJDJIynTC54yESGslrkmyP5ORBTO"  # bcrypt（goprox user/passwd 生成）
  # totp_secret: "GEZDGNBVGY3TQOJQGEZDGNBVGY3TQOJQ"   # 可选：TOTP 两步验证密钥，缺省/删除 = 关闭

services:
  # ① 本机服务：后端与网关同一台机器，host 用 127.0.0.1
  - id: jupyter
    name: "Jupyter Lab"
    description: "交互式笔记本"
    host: "127.0.0.1"
    port: 8888
    path: "/jupyter"
    websocket: true
    category: "开发工具"
    order: 0
    # bwlimit: 10485760              # 可选：带宽上限（字节/秒，0/缺省 = 不限速）

  # ② 局域网其他机器：host 填对方机器的局域网 IP（如 192.168.0.109）
  - id: rstudio
    name: "RStudio（服务器）"
    description: "运行在 192.168.0.109 的 RStudio Server"
    host: "192.168.0.109"
    port: 8787
    path: "/rstudio"
    websocket: true
    category: "开发工具"
    order: 1

  # ③ 单 HTML 网页：后端只提供一个入口文件（如数据分析报告）
  - id: report
    name: "分析报告"
    description: "单 HTML 网页报告"
    host: "127.0.0.1"
    port: 8080
    path: "/report"
    websocket: false
    category: "未分类"
    order: 2
    backend_path: "/report.html"    # 后端入口文件（见 BackendPath 详解）
host 可以是回环地址（127.0.0.1）或局域网私网 IP （192.168.x.x、10.x.x.x、172.16-31.x.x），也支持能解析到私网的主机名； 公网地址与链路本地/云元数据地址会被拒绝。

参数一览

参数类型必填默认值说明
namestring✅—卡片显示名称（≤200 字符）
hoststring—127.0.0.1后端地址，仅允许回环/私网 IP 或主机名
portint✅—后端端口（1–65535）
pathstring—按 id 自动生成前端访问路径，如 /jupyter；仅允许 A-Za-z0-9._~- 与 /，同用户内唯一
backend_pathstring—空后端实际监听子路径/文件（见 BackendPath 详解）
websocketbool—true是否允许 WebSocket 升级（Jupyter/RStudio 需开启）
bwlimitint—0该服务带宽上限（字节/秒），上行/下行各限；0/缺省 = 不限速
descriptionstring—空说明文字（≤500 字符）
categorystring—未分类分类/分组名（≤100 字符）
idstring—🔒 系统自动服务唯一 ID，由名称自动生成，重名自动加 -2、-3…
orderint—🔒 系统自动排序号（新增 = 最大 order+1，拖拽排序时更新）

局域网内的服务

后端跑在实验室的另一台机器上，host 填那台机器的局域网 IP：

services:
  - name: "RStudio（服务器）"
    host: "192.168.0.109"   # 对方机器的局域网 IP
    port: 8787
    path: "/rstudio"
    websocket: true

访问 http://网关:1908/proxy/alice/rstudio/ 即可，无需记住对方的 IP 和端口。

单 HTML 网页

想通过网关共享一个 HTML 报告（入口文件不在根路径时）：

services:
  - name: "分析报告"
    host: "127.0.0.1"
    port: 8080
    path: "/report"
    backend_path: "/report.html"   # 后端入口文件

访问 /proxy/alice/report/ → 后端收到 /report.html； 页面里的子资源（JS/CSS/图片）会相对入口文件所在目录解析。
